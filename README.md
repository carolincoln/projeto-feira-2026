# Projeto Feira Cultural 2026 - Turma 984

Projeto a ser apresentado pela **turma 984** durante a **Feira Cultural 2026** na **Escola Firjan Sesi Maracanã**. Este site une jogos desenvolvidos pela turma, com auxilio da turma de jogos, sobre temas relacionados às disciplinas de **Língua Portuguesa, Filosofia e Sociologia**.
